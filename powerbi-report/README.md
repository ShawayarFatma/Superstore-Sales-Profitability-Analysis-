# Power BI Dashboard Report

This folder contains the interactive Power BI dashboard for the Superstore Sales and Profitability Analysis project. The report uses a star-schema data model and DAX measures to explore sales performance, profit trends, and results across categories, regions, and states. It helps identify revenue drivers and underperforming areas to support data-driven decisions.

## Using the report

1. Download the `.pbix` file from this folder.
2. Open it with Microsoft Power BI Desktop.
3. Use the report pages, filters, and slicers to explore the sales and profitability data.

## Analysis focus

The dashboard is intended to help explore Superstore sales and profitability. It covers:

- Sales and profit trends
- Performance by product, category, or sub-category
- Regional and state-level results
- Key metrics and top or underperforming areas
